# Week 4 - Java OOP and Programming Constructs

This repository contains ten independent Java programs for Week 4.

## Practice Problems

1. M1 - Library Book Cataloguing: overloaded constructors and `this()` chaining.
2. M2 - Payroll Batch Bonus: `this` keyword with salary updates.
3. M3 - Late Fees: `final` methods and conditional batch processing.
4. M4 - One-Time College Setup: static block and student creation loop.
5. M5 - Account Batch Payments: inheritance and `instanceof` dispatch.

## Assignment Problems

1. A1 - Hackathon Registration: overloaded constructors and `this()` chaining.
2. A2 - Canteen Inventory: `this` keyword and batch restocking.
3. A3 - Parking Fine Calculator: `final` methods and conditional fine calculation.
4. A4 - Membership Card Setup: static block and object creation loop.
5. A5 - Payment Dispatch: inheritance, `instanceof`, and running totals.

## Main Concepts

Constructor overloading, `this()` chaining, field/parameter name clashes resolved with `this`, `final` methods, static blocks, arrays, loops, if-else conditions, inheritance, safe casting, and `instanceof`.

## Testing Status

All ten programs compile and run with the supplied sample data. Required edge cases for blank ISBN values, non-positive late days and overstay minutes, one-time static initialization, and `instanceof` dispatch have been checked. Generated `.class` files are ignored and removed after testing.
